市集在儀表板的「市集」。目錄來自一份簽過名的官方索引，跟這個版本的核心放在一起。畫面上的分類是金流、疊層、聊天室來源、工具。

伺服器每 6 小時會再讀一次索引並檢查簽章，不會自動安裝。「檢查更新」會立刻再驗一次。

## 簽章

索引是 JSON。核心用釘在程式裡的 Ed25519 公鑰驗證簽章，再用 SHA-256 核對每份 `s4n-plugin.json`。

下列情況整份索引都不會被採用：

- 沒有簽章
- 內容被改過，簽章對不上
- 簽章是另一把鑰匙產生的

這時市集會拒絕安裝。已經裝好的外掛不會被清掉，付款與疊層仍用程式裡的官方目錄。

這個版本不能在畫面上改索引網址。就算以後加上，仍然必須用同一把釘選的公鑰。

## 安裝、更新、移除

安裝之前會列出權限。要勾選「我已看過這些權限」才會寫入。新安裝的外掛是停用的，到「外掛」頁再啟用。密文留在那一頁。一般設定要等啟用後，才會出現在側欄「外掛」。

更新若沒有多權限，可以直接換版本。若多了權限，要再看一次，沒有同意就留在原版。

「釘選此版本」之後，更新會被拒絕，直到取消釘選。檢查仍會告訴你市集上有較新的版本。

若新版本沒有通過摘要或載入，安裝紀錄會回到更新前的版本與權限。畫面上會看到「新版本沒有載入，已回到原本的版本。」

移除時要選：

- 保留設定與密文：外掛從已安裝清單消失，資料還在。重新安裝後設定仍在。
- 刪除設定與密文：公開設定與 `EncryptedPluginSetting` 一起刪掉，不能復原。

## 哪些外掛可以裝

金流只允許官方索引裡的綠界與歐付寶。社群來源的付款外掛，或官方索引裡其他 id 的付款外掛，都會被拒絕。名字以 `official.` 開頭不夠。

社群外掛這個版本預設不能安裝。例外只有權限全部落在 `events.subscribe`、`overlay.slot`、`dashboard.settings`，而且種類只是疊層或儀表板的外掛。那種安裝只記下狀態，不會執行它的程式，也不會出現在 OBS。

官方外掛的程式仍是這個版本裡的檔案。索引負責說明版本、權限與摘要。摘要和檔案不一致時，不會安裝或更新。

## 紀錄

安裝、更新、移除、啟用、停用、釘選與回到上一版會寫進事件紀錄，類型是 `s4n.plugin.changed`。內容只有外掛 id、版本、權限名稱與是否保留資料。沒有設定值，沒有密文，沒有簽章私鑰。

這類紀錄不會送到 OBS，也不會跟著聊天或贊助的保留期限被刪掉。工作台的事件紀錄看得到一行摘要。

隨核心附上的官方外掛在第一次啟動時會標成已安裝，並保留你原本的啟用狀態與設定。這個補齊不會當成一次新的安裝去要求權限。
